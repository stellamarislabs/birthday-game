# Asset Pipeline Notes

The current build uses placeholder/procedural shapes and DOM/CSS UI only. No final art files, audio files, fonts, photos, or private memories are included yet. Small sound effects are generated in code through WebAudio and do not use asset files in this folder.

Guidelines for future parts:

- Prefer CC0 assets for rapid production.
- Track every third-party asset in `CREDITS.md`.
- Do not commit private photos, audio, messages, or personal materials unless explicitly requested.
- Keep sprites, images, fonts, and audio separated in their folders.
- Replace placeholders deliberately and document license/source details before release.
